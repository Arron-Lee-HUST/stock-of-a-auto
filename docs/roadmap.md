## 当前真实能力边界

这份清单描述的是仓库代码交付，不代表已经接通生产级实时行情或真实券商。

- AKShare 适配器提供日线历史数据和普通 spot 快照；免费上游稳定性与频率无 SLA。
- Tushare 适配器当前提供日线数据；Token 和数据权限由部署方自行配置。
- 竞价、分时、资金流和板块数据仍使用 CSV 上下文适配器；AKShare spot 不等同于竞价、逐笔或 VWAP 数据。
- `serve-akshare` 提供交易时段只读轮询、SQLite 告警去重和健康状态；仍需部署方提供权威交易日历及更新后的历史日线缓存。没有竞价/VWAP/市场宽度时会阻止新入场。
- HTML 仪表盘是离线报表，不是多用户在线交易终端。
- `PaperBroker` 是本地模拟成交，不代表真实盘口队列、部分成交和券商仿真。
- 没有真实下单接口，也没有自动实盘交易能力。

## 仍未完成的生产级能力

1. 免费源可持续、带明确时间戳的逐笔/盘口/竞价/分时/VWAP feed。
2. 权威市场宽度、板块和资金流数据的自动采集与 point-in-time 归档。
3. 企业微信/钉钉平台专用消息模板与签名适配（当前提供通用 JSON Webhook；平台特定签名/模板仍需适配）。
4. 自动更新且校验的交易日历、历史数据刷新任务、数据新鲜度和断线恢复。
5. 长时间运行的真实市场环境验收与样本外策略验证。

## 上线前必须完成

1. 确认行情供应商许可、字段单位、复权规则和历史数据可用性。
2. 建立覆盖沪深北、ST、上市初期、退市整理期等情况的交易规则表。
3. 使用真实交易日历，处理节假日、临时停牌和全天停牌。
4. 验证竞价/分时数据时间戳，严格防止未来函数。
5. 对策略做滚动样本外、不同市场状态、交易成本敏感性和压力测试。
6. 模拟盘持续运行并复盘，确认订单拒绝、数据中断、断线重连和告警机制。
7. 任何真实交易必须由独立、显式授权的券商适配层实现，并设置人工审批、限额和紧急停止开关。

历史回测和合成数据只用于工程验证，不构成收益承诺或投资建议。
