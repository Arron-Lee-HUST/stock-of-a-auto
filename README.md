# A股短线自动化交易系统

围绕「三驱一动」模型构建可配置、可回测、可解释的 A 股短线选股与交易决策系统。

> 本项目用于研究、策略验证与风险分析，不构成投资建议。任何策略均不保证收益；实盘前必须进行数据校验、回测、模拟盘验证，并遵守交易所规则。

## 核心模型

- 趋势动能：均线站位、涨幅区间、近期活跃度、突破结构。
- 资金博弈：成交量放大、量价关系、资金流向（数据源可选）。
- 市场情绪：板块热度、涨停梯队、消息催化（数据源可选）。
- 动态决策：竞价过滤、盘中均价线与量价确认、买卖纪律、仓位和市场状态风控。

策略参数、数据适配器和信号评分相互解耦；缺失的数据不会被伪造为通过，信号会保留可解释的原因与风险标记。
