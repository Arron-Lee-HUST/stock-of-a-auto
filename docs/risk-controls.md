# 组合级风险控制

`PortfolioRiskManager` 在产生新仓位前检查账户日内亏损、峰值回撤、总敞口、板块集中度、连续亏损次数和市场风险等级。

默认保护阈值（研究参数，可配置）：

- 日内亏损达到 2%：停止新增仓位。
- 账户峰值回撤达到 10%：停止新增仓位。
- 连续亏损达到 4 笔：停止新增仓位。
- 总敞口上限 80%。
- 单一板块敞口上限 35%。
- 市场谨慎时，总敞口目标降至 40%；risk_off 时停止新增仓位。

风控结果是下单前的硬性 gate，调用方必须先执行它，再结合单票仓位计算。此模块不负责自动平仓，也不覆盖交易所强制规则。阈值需要结合资金规模、策略波动和实盘风险承受能力评估。
